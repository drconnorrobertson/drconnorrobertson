- The default branch is `main`.

## Development Workflow

1. Make changes to `README.md` (or add static assets) as needed.
2. Commit with clear, descriptive messages.
3. Push to `main` for changes to appear on the GitHub profile.

## Guidelines for AI Assistants

- Do not add unnecessary tooling, CI/CD, or configuration files to this repository.
- Keep changes focused on profile content (README, images, etc.).
- Preserve the existing markdown structure and formatting of `README.md`.
- When editing the profile README, respect the owner's tone and style.
